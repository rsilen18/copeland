# Grover Juice Bar

![qr-code](qr-code.png)

Halloween party drink menu site. Pure HTML — no dependencies, no build step.

Open `groverjuice.html` in any browser.

## What it is

A retro/old-school styled drink menu for a Halloween party. Features:

- Menu of four drinks: Grover Juice v1, v2, v3, and Spreizer Juice
- "Create Your Own" form with custom ingredients, spookiness level, vessel, etc.
- No matter what you order or how you customize it, you get **Grover Juice Slushi**
- Everything comes with queso
